## 🖥 Project Overview

This project is a **server-side online book review application** built using **Node.js**, **Express.js**, and **JWT-based session authentication**.  
It provides a **secure REST API** for managing books, retrieving book details, adding/updating/deleting reviews, and managing users.

This was created as part of a Coursera lab to demonstrate **REST API development, authentication, and asynchronous programming with Promises & Async/Await**.

---

## Features

- **User Registration & Login** with session-level JWT authentication
- **REST API Endpoints** for:
  - Retrieving all books
  - Searching books by ISBN, author, or title
  - Reading book reviews
  - Adding, updating, or deleting book reviews
- **Async/Await and Promises** for asynchronous operations
- Fully documented for clarity and peer review
